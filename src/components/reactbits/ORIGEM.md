# Componentes React Bits

Copiados sem alterações do repositório oficial https://github.com/DavidHDev/react-bits
(variante `src/ts-default`, TypeScript + CSS simples), que é a mesma fonte do site https://reactbits.dev.

| Componente     | Origem no repositório                        | Dependência |
| -------------- | -------------------------------------------- | ----------- |
| Particles      | Backgrounds/Particles                        | ogl         |
| Galaxy         | Backgrounds/Galaxy                           | ogl         |
| BlurText       | TextAnimations/BlurText                      | motion      |
| ShinyText      | TextAnimations/ShinyText                     | —           |
| DecryptedText  | TextAnimations/DecryptedText                 | motion      |
| ClickSpark     | Animations/ClickSpark                        | —           |
| StarBorder     | Animations/StarBorder                        | —           |

Alternativa oficial pelo CLI (documentada em https://reactbits.dev/get-started/installation):
`npx shadcn@latest add @react-bits/SplitText-TS-CSS` — troca o nome e o sufixo (JS/TS + CSS/TW).
